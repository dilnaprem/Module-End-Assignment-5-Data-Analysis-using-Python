# Social Media Engagement Analytics Using Python

## Project Overview

This project focuses on analysing social media engagement using Python. The dataset contains 5,000 records. The main goal is to understand user engagement and identify patterns in social media posts.

## Tools & Libraries Used

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Work Done

- Data cleaning and preprocessing
- Handling missing values and duplicates
- Exploratory Data Analysis (EDA)
- Data grouping and calculations
- Outlier detection
- Data visualization
- Sentiment analysis
- Interactive charts using Plotly

## Visualizations

**Plotly:**
- Interactive Line Chart
- Interactive Bar Chart
- Interactive Scatter Chart
- Bubble Chart

## Key Findings

- Video posts have the highest engagement.
- Food is the best-performing content category.
- Brazil has the highest average engagement rate.
- Age 24 shows the highest average engagement rate.
- Verified accounts have slightly higher engagement.
- Tuesday has the highest average impressions.
- Mobile users have the highest watch time.
- Negative sentiment posts have the highest engagement rate.
